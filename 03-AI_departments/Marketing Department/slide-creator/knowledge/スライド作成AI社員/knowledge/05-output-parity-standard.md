# 05-output-parity-standard.md — セミナープレゼン作成AI社員

## 内部AI社員との比較基準

- 内部参照: （社内の実スキルを元に一般化・本パックで自己完結）
- 外部配布版で再現する思想: 基準デッキの表紙・自己紹介・実績・章扉・証拠壁・クロージングを固定資産化し、テーマ部分だけ差し替える。
- 目視/検証観点: 全スライドスクショ、接触シート、文字折れ、画像比率、同型連続、CTA弱さを確認する。

## このAI社員が必ず出すべき成果物

- `brief.md`
- `questions.md`
- `story-plan.md`
- `source-map.md`
- `slides/index.html`
- `screenshots/final/`
- `review-notes.md`

## 内部品質に近づけるための判断

1. 完成物だけでなく、判断理由・前提・未確認事項・次アクションを残す。
2. 固有素材や実案件データは同梱しない。ユーザーの入力欄として開けておく。
3. 目に見える成果物は、スクショ・HTML・CSV・Markdownなど確認しやすい形にする。
4. 送信、投稿、公開、請求、契約など外部に出る行為は下書きで止める。
5. 次回も同じ品質で作れるように、良かった完成物を判断基準に分解する。

## 評価表

| 評価軸 | 点数(1-5) | 5点の条件 |
|---|---:|---|
| 出力契約 |  | 最低成果物が明確で、人間が次工程にそのまま使える |
| 内部品質との一致 |  | 内部AI社員の思想・構成・確認手順を外部安全版に抽象化できている |
| 入力設計 |  | 不足情報を10問以内で埋め、仮定と一次情報を分けられる |
| 成果物密度 |  | 完成物、判断理由、未確認事項、次アクション、品質チェックまで揃う |
| 実行性 |  | 該当領域はスクリプトやテンプレで再現でき、属人的な口頭指示だけに依存しない |
| 目視QA |  | HTML/画像/動画/資料系はスクショや一覧で崩れを確認できる |
| 外部配布安全性 |  | 個人情報・顧客情報・実案件素材・専有アーカイブを同梱しない |
| 再現性 |  | 良い完成物を丸コピーせず、判断基準として次回へ残せる |
| 事業接続 |  | 見た目や作業で終わらず、売上・申込・運用・教育などの成果に接続する |
| 承認ゲート |  | 送信・投稿・公開・請求・契約など外部実行は人間承認前で止める |
