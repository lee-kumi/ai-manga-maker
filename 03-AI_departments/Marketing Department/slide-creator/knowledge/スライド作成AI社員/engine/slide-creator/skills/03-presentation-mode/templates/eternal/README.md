# 永久テンプレ (Eternal Templates) — そのまま使うやつ

`templates/snippets/` (普通テンプレ・型) とは別物。**ここに入ってるのは「完成品」**。
新規デッキ制作時、**文字を変えず、レイアウトも触らず、そのまま貼る**。

## 使い方

1. デッキ作成時、自己紹介スライドが必要 → `eternal/01-speaker-self-intro.html` の `<section class="slide">...</section>` をそのままコピー
2. アセット (`assets/people/speaker_cutout.png` 等) も一緒にコピー
3. 数字 (フォロワー数・売上等) だけ最新に差し替え。**それ以外触らない**
4. レイアウト変更・装飾追加・色変更は禁止

## なぜ「そのまま」か

過去のパートナー × AIツール × ナレッジ管理セミナーで投影・好評だった完成品。型を再発明する必要がない。
毎回ゼロから自己紹介スライドを設計すると、品質ブレ・時間浪費・「ここまで伸ばせました」感の消失が起きる。

## 普通テンプレと永久テンプレの違い

| 観点 | 永久テンプレ (eternal/) | 普通テンプレ (snippets/) |
|------|---------------------|----------------------|
| 中身 | 完成スライド | 型 (placeholder) |
| 文字 | 数字だけ差し替え | 全部差し替え前提 |
| 用途 | 毎回必要な定番 (自己紹介・実績) | 内容によって組む本文 |
| 編集 | 触らない (R13) | 内容に合わせて編集 |
