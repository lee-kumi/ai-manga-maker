2
6つの用語を
覚える
6 WORDS
AIRCLE
用語 01 ・ REPOSITORY
リポジトリ＝箱
1プロジェクト＝1リポジトリ。コード・画像・説明書（README）をまとめて入れる。
公開／非公開を選べる。
AIRCLE
用語 02 ・ COMMIT
コミット＝セーブ
「ここまでやった」と名前をつけて記録する。1コミット＝1つの区切り。
メッセージを書くと、後から履歴が読める。
AIRCLE
用語 03 ・ PUSH / PULL
送る と 取ってくる
push ⬆
手元のコミットを
GitHubへアップロード
pull ⬇
GitHubの最新を
手元へダウンロード
AIRCLE
用語 04 ・ BRANCH
ブランチ＝分身
本番（main）を触らず、別レーンで安全に作業する仕組み。
失敗しても本番は無傷。たとえ：清書はそのまま、下書き用紙で試す。
AIRCLE
用語 05 ・ MERGE
マージ＝合流
ブランチの変更を本番（main）に取り込む。複数人の変更もここで1つにまとまる。
ぶつかったら「どちらを採用するか」選ぶだけ。
AIRCLE
用語 06 ・ PULL REQUEST
プルリク＝合流の申請
「このブランチをmainに入れていい？」とチームに提案する場。
変更をみんなで見てレビューし、OKが出たらマージ。共同開発の心臓部。
AIRCLE
基本の6歩（これだけ覚える）
ブランチ → 変更 → commit → push → PR → merge
この1周ができれば、チーム開発の入口はクリア。

HANDS-ON
AIRCLE
準備するもの
・GitHubアカウント（github.com で Sign up）
・おすすめ：GitHub Desktop（コマンド不要のアプリ）
・慣れたい人：ターミナル＋VS Code
難しいコマンドは「困ったらAIに貼って聞く」でOK
AIRCLE
HANDS-ON ①
リポジトリを作る
・GitHub右上の「＋」→ New repository
・名前を入れる（例：aircle-github-practice）
・「Add a README」にチェック → Create
これで「プロジェクトの箱」がクラウドに完成。中身は空でOK。
AIRCLE
HANDS-ON ②
手元に持ってくる（clone）
GitHub Desktopなら「Clone」ボタン一つ。コマンド派はこちら：
git clone https://github.com/<あなた>/aircle-github-practice.git
clone＝GitHubの箱を、そのまま自分のPCにコピー
AIRCLE
HANDS-ON ③
変更して、セーブ（commit）
READMEに自己紹介を1行足して、保存したら：
git add . git commit -m "READMEに自己紹介を追加"
add＝セーブするファイルを選ぶ／commit＝メモをつけてセーブ
AIRCLE
HANDS-ON ④
GitHubへ送る（push）
git push
ブラウザでリポジトリを更新すると、変更が反映されている。
クラウドに自分の作業が乗った瞬間🎉
AIRCLE
HANDS-ON ⑤
ブランチ → プルリク体験
git switch -c my-first-branch git commit -am "変更" git push -u origin my-first-branch
GitHubに出る「Compare & pull request」→ 説明を書いて Create → Merge
