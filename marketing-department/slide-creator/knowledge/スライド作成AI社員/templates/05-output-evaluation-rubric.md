# 05-output-evaluation-rubric.md — セミナープレゼン作成AI社員

## 納品前評価

| 評価軸 | 点数 | 修正メモ | OK条件 |
|---|---:|---|---|
| 出力契約 |  |  | 最低成果物が明確で、人間が次工程にそのまま使える |
| 内部品質との一致 |  |  | 内部AI社員の思想・構成・確認手順を外部安全版に抽象化できている |
| 入力設計 |  |  | 不足情報を10問以内で埋め、仮定と一次情報を分けられる |
| 成果物密度 |  |  | 完成物、判断理由、未確認事項、次アクション、品質チェックまで揃う |
| 実行性 |  |  | 該当領域はスクリプトやテンプレで再現でき、属人的な口頭指示だけに依存しない |
| 目視QA |  |  | HTML/画像/動画/資料系はスクショや一覧で崩れを確認できる |
| 外部配布安全性 |  |  | 個人情報・顧客情報・実案件素材・専有アーカイブを同梱しない |
| 再現性 |  |  | 良い完成物を丸コピーせず、判断基準として次回へ残せる |
| 事業接続 |  |  | 見た目や作業で終わらず、売上・申込・運用・教育などの成果に接続する |
| 承認ゲート |  |  | 送信・投稿・公開・請求・契約など外部実行は人間承認前で止める |

## 最低合格ライン

- 合計40点以上
- `privacy`（表の「外部配布安全性」）と `approval_gate`（表の「承認ゲート」）は必ず5点
- HTML/画像/資料系はスクショまたは表示確認を残す
- 請求書/契約/投稿/配信/公開は人間承認前で止める
